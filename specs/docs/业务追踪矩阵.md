# 前端业务到后端验收追踪矩阵

业务来源为 `02-chayitong` 当前代码，而非仅依据早期计划书。此矩阵用于防止实现只覆盖旧后端已经练习过的部分。

| 前端页面/能力 | 后端模块 | 核心接口或规则 | 验收场景 |
| --- | --- | --- | --- |
| 首页 Banner、节气、精选 | 内容首页 | `GET /api/home`、`GET /api/app-config` | E01、发布态与精选顺序 |
| 百科六类筛选、专题 | 茶/文章 | `GET /api/teas`、`GET /api/articles` | 57/20 种子、六类数量、专题下架 |
| 茶详情、冲泡、相关推荐 | 茶 | `GET /api/teas/{id}` | 完整参数、Top 3 关联 |
| 文章详情、七种正文块 | 文章 | `GET /api/articles/{id}` | 块保序与关联茶 |
| 联合搜索、热门词 | 搜索 | `GET /api/search` | 先过滤后分页、二字片段、同义词 |
| 15 题荐茶、结果恢复 | 推荐 | `GET /api/quiz`、`POST/GET /api/recommendations` | 固定答案 Top 3、下线过滤 |
| 首次进入与跨设备身份 | 认证 | 微信 code 登录、刷新、退出 | 同 openid 单用户、令牌撤销 |
| 个人资料、等级、每日积分 | 用户 | `GET/PATCH /api/me`、summary、daily-points | 长度枚举、并发每日 5 分、九级 |
| 收藏列表和详情收藏 | 个人资产 | `PUT/DELETE/GET /api/me/favorites` | 幂等、有效计数、归属 |
| 浏览足迹、50 条上限 | 个人资产 | `PUT/DELETE/GET /api/me/history` | 去重、淘汰、清空 |
| 社区列表、话题筛选 | 社区 | `GET /api/posts` | 发布态、稳定最新排序 |
| 发布图文/视频、我的动态 | 社区/媒体 | `POST /api/posts`、`GET /api/me/posts` | 9 图/视频互斥、幂等、作者归属 |
| 点赞、评论、删除 | 社区 | like/comments/delete 接口 | 计数事务、权限、重复请求 |
| 商城分类、商品规格 | 商品 | `GET /api/products/{id}` | 在售过滤、规格价格 |
| 购物车、勾选与合计 | 购物车 | `/api/cart/**` | 实时计价、失效项、数量边界 |
| 结算与到店自取 | 订单 | quote、create、list/detail | 服务端计价、快照、库存预占 |
| 支付结果、取消 | 支付/订单 | payments、payment-result、cancel | 状态机、DEMO 隔离、可信结果 |
| 头像和社区媒体 | 媒体 | `POST /api/media`、内容读取 | 类型大小、归属与绑定 |
| 内容与商品后台维护 | 管理 | `/api/admin/**` | 普通用户 403、发布/上下架 |

## 不直接后端化的前端职责

- 页面加载/空/错误/离线状态、轮播、动画、折叠、滚动与导航。
- 时间、金额、水温等展示格式化。
- 最近搜索、本地弱网缓存和待同步队列。
- 清除本机缓存不等于删除服务端账号或 UGC。

## 有意的后端化修正

- 本地 mock 用户改为微信身份与可撤销令牌。
- 本地收藏/足迹/社区/购物车/订单改为服务端持久化。
- 客户端商品快照和金额改为服务端 SKU 计价。
- 先分页后搜索改为数据库完整过滤再分页。
- 展示点赞基数与本地动作叠加改为权威真实计数。
- 本机动态置顶改为统一时间分页；种子运营顺序如需保留必须显式使用 curated 模式。
- 模拟支付不再自动伪装真实支付，生产环境默认关闭。
