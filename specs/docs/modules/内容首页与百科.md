# 内容、首页与百科模块

## 1. 内容基线

以纯前端当前种子和运行逻辑为准：57 款发布名茶、20 篇文章。六类茶数量分别为绿茶 12、白茶 9、黄茶 6、青茶 10、红茶 10、黑茶 10。旧文档与代码不一致时，以当前页面和服务行为为业务来源。

游客无需登录即可访问首页、百科、茶和文章详情。所有公开查询强制 `status=published`，不接收客户端 status 覆盖；草稿/下架公开详情与不存在统一返回 404。

## 2. 茶模型

- 稳定字符串业务 ID、唯一 slug、名称、别名数组、茶类、三级产地、摘要。
- 工艺、香气、滋味、适饮场景均为有序字符串数组。
- 冲泡参数：投茶克数、水量 ml、茶水比、最低/最高水温、器具数组、首泡秒数范围、后续浸泡提示、耐泡次数范围、方法提示。
- 储存：方法和保质/陈化提示；另有饮用提示、封面、图集、结构化正文、关联商品 ID。
- 运营字段：featured、sort、status、createdAt、updatedAt。
- 数值必须为正且范围 `min <= max`；slug 唯一；公开列表按 `sort ASC,id ASC` 稳定排序。
- 茶类枚举固定为 `green/white/yellow/oolong/black/dark`，其中 `black` 是红茶，`dark` 是黑茶；不得新增 `red`。

## 3. 文章模型

- 稳定 ID、唯一 slug、标题、摘要、分类、标签、封面、结构化正文、关联茶 ID、阅读分钟数、展示阅读量。
- 运营字段：featured、sort、publishedAt、status 和审计时间。
- 分类：`tea_basics/brewing/storage/teaware/tea_history/sensory`。
- `viewCountDisplay` 是内容展示值，不伪装为真实访问统计，首版不提供阅读计数写接口。
- 列表不加载正文，按 `sort ASC,id ASC`；支持 category、featured、keyword 和分页。
- 文章发布前校验标题、摘要、分类和正文完整性；首版管理生命周期支持草稿创建/修改/发布/撤回/删除。已发布文章先撤回再编辑或删除，重复发布保持首次发布时间。

## 4. 结构化内容块

正文是 JSON 数组，数组顺序即展示顺序，不保存整段 HTML。严格拒绝未知块类型和字段。

| type | 必需字段 | 可选字段与约束 |
| --- | --- | --- |
| `heading` | `text`,`level` | level 仅 2/3/4 |
| `paragraph` | `text` | — |
| `image` | `src`,`alt` | `caption` |
| `quote` | `text` | `source` |
| `list` | `items`,`ordered` | items 为字符串数组 |
| `steps` | `items` | 每项含 `title`,`text` |
| `tip` | `text`,`tone` | tone 为 info/warning/success，可选 title |

图片 src 必须是受控 HTTPS 地址或本系统文件 URL。后端验证结构与顺序，前端负责渲染和折叠。

## 5. 首页与配置

`GET /api/home` 聚合生产配置、精选茶和精选文章；`GET /api/app-config` 返回公开运营配置。

- 配置 ID 固定 `production`，含版本、节气主题、Banner、精选 ID、公告、功能开关。
- 精选结果严格按配置 ID 数组顺序；已下架或不存在的引用省略，不阻塞整个首页。
- 首页精选茶最多返回 4 款；精选文章保持契约，即使当前首页未渲染。
- 节气 dateRange 是内容字段，不擅自按日期自动轮换。
- 补充 `wikiTopics`、`wikiHeroArticleIds`、`searchHotKeywords`、节气推荐香气和水温，移除前端硬编码。
- 百科专题首版映射：冲泡、储存、茶器、茶史到配置文章；目标失效时由前端搜索兜底。
- 管理配置仅管理员可写，公开响应不包含密钥或内部备注。

## 6. 详情关联

- 茶详情的 `relatedTeas` 保持现有规则：全部发布茶中排除自身，按 `sort ASC,id ASC` 取前三款。
- 文章详情按 `relatedTeaIds` 找到发布茶，但保持现有全局茶排序，取前三款；无关联返回空数组。
- 不把关联解析交给客户端下载全量内容。
- 健康相关内容仅作茶文化科普，不生成诊疗或功效承诺。

## 7. 管理接口

- 茶：`GET /api/admin/teas`、`POST /api/admin/teas`、`GET/PUT/DELETE /api/admin/teas/{id}`。
- 文章：`GET/POST /api/admin/articles`、`GET/PUT/DELETE /api/admin/articles/{id}`、`PUT/DELETE /api/admin/articles/{id}/publication`。
- 配置：`PUT /api/admin/app-config`。
- 管理查询可读取草稿，公开查询永远不可；所有变更校验关联 ID 和内容块。

## 8. 验收

1. 种子导入后总数 57/20，六类筛选数量准确。
2. 公开接口不泄露草稿；精选中的下架项被省略且顺序稳定。
3. 相同 sort 的数据连续翻页不重复不遗漏，total 准确。
4. 西湖龙井详情包含 3g/150ml、80–85℃、首泡 20–30 秒等完整参数。
5. 七种内容块均严格校验和保序；未知类型/字段、非法范围返回 400。
6. 文章发布/撤回/编辑/删除状态冲突返回 409，重复发布不改变首次发布时间。
7. 首页、百科专题和详情关联在目标下架时不泄露内容且服务不中断。
