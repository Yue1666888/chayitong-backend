# 媒体文件模块

## 1. 目标

将头像、动态图片/视频和内容图片从本机临时路径转为可持久化、可授权、可引用的服务端媒体。二进制与业务记录分离，数据库保存元数据和对象 key。

## 2. 上传与元数据

- `POST /api/media` 要求登录，multipart 字段为 file 和 purpose；purpose 支持 avatar/post/content/product。
- 普通用户仅 avatar/post；content/product 仅管理员。
- 响应：mediaId、url、mediaType、mimeType、sizeBytes、可选宽高/时长和创建时间。
- 媒体字段：ID、所有者、用途、存储方式、bucket/objectKey、原始文件名、MIME、大小、SHA-256、状态、绑定资源、审计时间。
- 对象名由服务端随机生成，不使用原始文件名做路径，不覆盖其他对象。
- 状态 `UPLOADED/BOUND/DELETED`；发布动态或更新头像时校验归属、用途和绑定状态。
- 业务记录引用 mediaId，展示时解析为 URL；禁止 wxfile、本机路径和可执行内容。

## 3. 类型与限制

- 图片允许 JPEG/PNG/WebP，检查 multipart 类型、扩展名和实际文件头/解码结果；头像与动态单张最大 5 MiB。
- 视频允许 MP4，检查签名，单文件最大 20 MiB，首版时长上限 60 秒（无法读取时拒绝而非盲信客户端）。
- 动态发布最多 9 图或 1 视频，业务模块再次校验数量与互斥。
- 超限返回 413，非法类型/损坏文件 400；不上传 HTML、SVG、脚本或可执行文件。
- 读取文件使用受控临时流/大小限制，不把超大文件无界加载到内存。

## 4. 存储与访问

- 定义 MediaStorage 接口，隔离本地磁盘、腾讯云 COS 与 S3 兼容对象存储。
- 本地存储仅用于 dev/test，根目录通过配置指定，不作为多实例生产方案。
- 生产默认使用腾讯云 COS，secretId、secretKey、region、bucket 和对象前缀均来自环境变量；密钥不入库、不入日志。S3 兼容存储保留为可选适配。
- `EXTERNAL` 只用于种子迁移的受控 HTTPS 图片/视频：保存原地址并直接用于展示，内容接口可重定向；普通上传不能选择此类型。
- 首版公开媒体通过受控 GET `/api/media/{id}/content` 或配置的公开 CDN URL 访问；私有下载和签名 URL 只有出现私有业务时再引入。
- 删除业务内容不立即物理删媒体，避免历史引用破坏；孤儿/删除清理由独立维护任务按规则执行。

## 5. 安全与一致性

- 上传先鉴权再解析，限制请求大小；trace 日志不记录二进制和认证头。
- 媒体绑定检查所有者、用途、状态和目标类型，不能跨用户或跨业务重放。
- 数据库元数据与对象写入失败需要补偿清理；绑定事务失败不改变媒体归属。
- 内容安全审核不是首版自动能力，生产上线仍需微信内容安全或人工审核流程，文档不得宣称已具备。

## 6. 验收

1. 未登录上传 401，普通用户上传 content/product 403。
2. 合法 JPEG/PNG/WebP/MP4 可保存并读取，元数据正确。
3. 伪造扩展名、损坏内容、超限文件被拒绝，不产生可引用元数据。
4. 用户不能使用他人媒体、错误用途或已绑定媒体发帖。
5. 本地存储路径穿越和原始文件名注入无效，生产配置缺失时启动/调用明确失败而不降级本地。
