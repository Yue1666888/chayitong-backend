# 搜索、荐茶与答题模块

## 1. 联合搜索

- `GET /api/search?keyword=...&pageNum=1&pageSize=20` 为公开接口。
- 关键词 trim 后必填；空白返回 400，不返回全量数据。
- 同时搜索发布态茶、文章和在售商品，三组分别返回统一分页数据；前端仍按商品、茶、文章分组展示。
- 正确执行顺序：公开状态过滤 → 关键词匹配 → `sort ASC,id ASC` → 分页。禁止复现旧云仓储“先分页再过滤”的漏结果。
- 搜索字段：茶名称/别名/摘要/香气/滋味/工艺/场景/产地/器具；文章标题/摘要/标签/全部块；商品名称/副标题/标签/SKU/详情块。
- 中文分类同义词参与匹配，尤其“乌龙茶”命中 `oolong`。
- 先完整子串匹配；未命中时拆为相邻二字片段，任一片段命中即命中。首版保持该可解释算法，不伪造相关度分。
- 最近搜索最多 5 条仅属页面状态，继续由前端维护；热门词来自公开配置。

## 2. 问卷

`GET /api/quiz` 公开返回当前启用问卷及版本，不下发评分权重。问卷固定 15 题，每题 key 唯一，选项 value 在题内唯一，数组顺序即答题顺序。

题目 key：`taste, aroma, texture, aftertaste, strength, time, scene, effort, vessel, temp, season, pairing, explore, experience, focus`。每题单选且全部必答；未知 key、缺题、未知选项和版本不存在均返回 400。

## 3. 推荐评分

`POST /api/recommendations` 输入 `{quizVersion, answers}`，公开可用。全部发布茶参与评分，按命中规则累加主分，满分 39。

| 问题 | 权重 | 选项到茶类 |
| --- | ---: | --- |
| taste | 4 | fresh→绿/黄；sweet→红/白/黄；soft→白/红；rich→青/黑 |
| aroma | 4 | floral→绿/青；fruity→红/青；roasted→青/黑；aged→黑 |
| texture | 3 | crisp→绿/白；smooth→白/红/黄；thick→青/黑；brisk→绿/青 |
| aftertaste | 3 | clean→绿/白；sweet→绿/青/黄；deep→青/黑；warm→红/青 |
| strength | 3 | light→白/绿；medium→黄/红；rich→青/黑 |
| time | 3 | morning→绿/黄；afternoon→白/青；evening→红/黑 |
| scene | 2 | work→绿/白；ritual→青；meal→红/黑；share→青/红 |
| effort | 2 | quick→绿/白/红；normal→黄/红/白；slow→青/黑 |
| vessel | 2 | glass→绿/黄/白；gaiwan→全部；zisha→黑/青；tumbler→绿/白/红 |
| temp | 2 | hot→青/黑/红；warm→全部；cooled→白/青；cold→绿/白 |
| season | 2 | spring→绿/白；summer→绿/黄/白；autumn→青/白；winter→红/黑 |
| pairing | 2 | nothing→全部；snack→绿/白/青/黄；heavy→黑/红/青 |
| explore | 3 | classic→绿/青/红；niche→黄/白/黑 |
| experience | 2 | new→绿/白/红/黄；familiar→青/黑 |
| focus | 2 | bud→白/黄；leaf→绿/白；cake→黑；fire→青 |

茶类内部顺序映射为 `green/white/yellow/oolong/black/dark`。

特征分用于同主分排序，不进入匹配度。香气、口感、回甘、季节、场景、浓度六维各 0～1，总分 0～6；通过答案关键词与茶内容匹配计算。

最终按 `score DESC → traitScore DESC → sort ASC → id ASC` 取 Top 3。匹配度 `min(98, 62 + round(score / 39 * 36))`，是展示值而非统计概率。

理由按评分规则顺序收集；没有理由时用前两个香气兜底；不足三条依次补产地省份、建议水温；最多三条。

## 4. 结果持久化

- 保存不可预测的高强度 resultId、问卷版本、答案、每款茶评分/特征分/匹配度/理由和创建时间。
- `GET /api/recommendations/{resultId}` 公开读取单个结果，不提供结果列表。
- 读取时关联当前发布茶；已下线茶从结果视图过滤，但原评分记录不被篡改。
- 不依赖登录，不建立用户画像；最近结果本地缓存仅用于弱网恢复。
- 服务端对相同答案和版本的重复提交可做短期幂等，但结果读取不暴露他人敏感信息，因为答案仅为饮茶偏好。

## 5. 保留在前端的行为

单题单屏、上一步、必答交互、防重复点击、结果动画、单位格式化和最近结果缓存不属于服务端。推荐不引入机器学习、大模型或登录门槛。

## 6. 验收

1. 问卷恰为 15 题；缺题、额外 key、非法选项和错误版本均 400。
2. 搜索“西湖龙井”“安溪”“乌龙茶”命中预期字段；空白关键词 400，无结果返回三个空组。
3. “普洱茶”能通过二字片段命中“普洱熟茶”；命中分散在不同位置时 total 与分页仍正确。
4. 固定回归答案 `fresh/floral/crisp/light/clean/cold/morning/work/glass/quick/spring/snack/classic/new/leaf`（按各自 key 提交）结果依次为：黄山毛峰 39/6/98、碧螺春 39/5/98、西湖龙井 39/3/98。
5. 推荐只使用发布茶；结果保存后可恢复，茶下线后读取结果过滤该茶。
6. 同输入重复计算结果一致，排序和理由稳定。
