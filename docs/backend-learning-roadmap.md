## 文章综合练习

- [x] 实现管理员 `DELETE /api/admin/articles/{id}`，事务内检查状态后删除草稿。
- [x] 自动验证发布状态保护、权限、CSRF 和删除后的可见性。38 项文章集成测试通过。
- [ ] 用 Apifox 完成下面的综合练习。全程用同一个临时文章编号。

| 顺序 | 请求 | 预期结果 |
|---|---|---|
| 1 | `POST /api/admin/articles` | `201`，记下新文章的 `id` |
| 2 | `PUT /api/admin/articles/{id}` | `204`，提交完整编辑 JSON |
| 3 | `GET /api/admin/articles/{id}` | `200`，读回更新内容和 `draft` 状态 |
| 4 | `PUT /api/admin/articles/{id}/publication` | `200`，公开详情也返回 `200` |
| 5 | `DELETE /api/admin/articles/{id}` | `409`，文章仍处于已发布状态 |
| 6 | `DELETE /api/admin/articles/{id}/publication` | `204`，公开详情变为 `404`，管理详情显示草稿 |
| 7 | `DELETE /api/admin/articles/{id}` | `204`，管理详情和再次删除均返回 `404` |

由你重启后端后登录管理员。POST、PUT 和 DELETE 需要 Cookie 和登录后的 CSRF 请求头。第 1 步与第 2 步提交标题、分类和有效正文，发布及 DELETE 请求的 Body 留空。
